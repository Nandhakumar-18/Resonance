# Resonance 🌊

**Resonance** is a next-generation social interaction prototype that completely abandons traditional social media paradigms—no infinite scrolling feeds, no follower counts, and no static user profiles.

Instead, Resonance focuses on **ephemeral, present-moment connection** based on your current "vibe" or frequency. It's designed to foster serendipitous, meaningful, and low-pressure interactions.

---

## 🚀 The Core Experience

### 1. The Tuner
You don't create a profile; you create a state. Using a 2D spatial pad, you set your current **Frequency**:
- **X-Axis:** Energy (from Calm to High-Energy)
- **Y-Axis:** Mood (from Melancholy to Joyful)
You can then broadcast a short, ephemeral thought. The entire UI color palette dynamically shifts to reflect your exact coordinates, creating a visual representation of your current state.

### 2. The Radar (Discovery)
Once you tune in, you enter the Radar view. The traditional feed is replaced by a pulsing, spatial interface. 
Other users appear as blips on your radar. A user's physical proximity to the center is determined by how closely their frequency matches yours. Hover over a blip to read what they are currently thinking.

### 3. The Sync (Interaction)
When you find someone resonating on a similar frequency, you can initiate a **Sync**. This drops both users into a temporary, split-screen connection where your distinct frequency colors blend into a shared gradient. 
- You can exchange thoughts and messages.
- **It is highly ephemeral:** A 60-second timer ticks down. Once it hits zero, the connection dissolves completely like smoke. No chat history is saved.

## 🛠️ Tech Stack

This project was built focusing on fluid, immersive, and responsive frontend experiences:

- **Framework:** React 18
- **Build Tool:** Vite
- **Language:** TypeScript
- **Styling:** Tailwind CSS v4
- **Animations & Physics:** Framer Motion (Powers the fluid radar UI and spring-physics view transitions)
- **Icons:** Lucide React

## 🏃‍♂️ Running Locally

1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/Resonance.git
   ```
2. Navigate into the directory:
   ```bash
   cd Resonance
   ```
3. Install dependencies:
   ```bash
   npm install
   ```
4. Start the development server:
   ```bash
   npm run dev
   ```

## 🌐 Deployment
This application is fully optimized to be deployed on platforms like **Vercel** or **Netlify** with zero configuration required.
